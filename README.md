# Alcance Live Translate

Tradução simultânea por IA para a Alcance Myrtle Beach (piloto, português → inglês).

- `index.html` — página do participante (abre pelo QR Code).
- `operador.html` — painel do operador, aberto no computador da mesa de som.
- `src/` + `build.py` — modelos das páginas; `python3 build.py` gera os arquivos finais.

Nenhuma chave ou segredo fica neste repositório. A chave da OpenAI é digitada no painel do operador e fica salva só no computador da igreja.
